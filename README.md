# Hi, I'm Denise! 👋

I am a Software Engineering student who enjoys learning about software development and building applications that can solve real-world problems. I am particularly interested in backend development, web applications, databases, and exploring how different technologies can work together to build a complete system.

Throughout my studies, I have worked on different software projects, which have given me experience in programming, software testing, databases, APIs, and system development. These experiences have also made me realise that developing a software system is only one part of the process. Keeping the system working, improving it, and adapting it to new requirements are equally important.

## My Expectations for WIF3005 SOFTWARE MAINTENANCE AND EVOLUTION 📚

For the **Software Maintenance and Evolution** course, I hope to gain a better understanding of how software systems are maintained and evolved after their initial development. I would like to learn more about topics such as maintaining existing code, identifying and fixing problems, refactoring, software evolution, and managing changes to a system over time.

I also hope that this course will help me understand how software engineers work with existing codebases rather than always starting a project from scratch. I believe this will be useful for my future career because real-world software often needs to be continuously maintained and improved.

Most importantly, I hope to gain practical knowledge that I can apply to my future software projects and become a better software engineer.
